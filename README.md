# Block-World-Survival-Game
Unity 开发的方块世界生存闯关游戏

## 项目简介
基于 Unity 开发的3D生存闯关游戏，玩家需要在方块世界中收集资源、搭建建筑、对抗敌人，完成闯关目标。

## 技术栈
- 开发引擎：Unity
- 开发语言：C#
- 核心技术：场景搭建、角色控制、AI行为、碰撞检测、UI系统

## 核心功能
- 玩家移动与视角控制
- 方块放置与破坏系统
- 敌人生成与AI寻路
- 资源收集与物品系统
- 关卡进度与存档系统

## 运行说明
1. 使用 Unity 202X.X 新建工程
2. 导入仓库中的 `Block-World-Game.unitypackage` 文件
3. 打开主场景，点击运行即可体验
